HTML * CSS * JavaScript

Bem-vindo!

Este é um exemplo que demonstra a integração entre HTMl, CSS e JS na construção de um site moderno.

HTML

HTML é uma linguagem de marcação utilizada para criar páginas web. Não uma linguagem de programação. Sendo considerado o esqueleto do site.

CSS

CSS é uma linguagem de estilo utilizada para definir a aparência visual de páginas web. Ele permite controlar cores, fontes, layouts e outros aspectos visuais

Java Script

Java Script é uma lingugagem de programação interpretada e dinâmica. É uma das principais linguagens do frontend no desenvolvimento web.
